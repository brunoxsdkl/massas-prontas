# Massas Prontas - Site de Produtos

Site institucional de empresa de massas prontas com página de produtos, inspirado no layout de catálogo de produtos.

## Estrutura
- `index.html` - página principal com grade de produtos
- `assets/css/style.css` - estilos (paleta vermelho/azul, fonte Montserrat)
- `assets/img/` - imagens SVG dos produtos

## Deploy
Hospedado na Vercel. Para editar, altere os arquivos e faça push para o GitHub.
